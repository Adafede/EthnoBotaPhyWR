    EthnoBotaPhyWR

    EthnoBotaPhyWR combines ethnobotanical use records and phytochemical occurrence data from Wikidata and LOTUS on Open Tree of Life phylogenies.

    Scope and exported API

    The package exports a single pipeline entry point alongside curated Orchidaceae datasets:

    • ethnobotafever_tree() runs the end-to-end analysis for any plant family, querying Wikidata (via QLever), Open Tree of Life, and NPClassifier, computing diversity and phylogenetic metrics, and exporting trees, tables, and iTOL annotations.
    • orchids_compounds (3,055 rows), orchids_compound_classes (1,574 rows), and orchids_ethnobotanical (419 rows) are curated plain data.frame objects for Orchidaceae.
    • trees_dec344ba7ea88a268b3feac0403844a3 and trees_9f61da756dff1e09426c110eefce3824 store precomputed Open Tree of Life phylo caches for the bundled Orchidaceae run.
    • system.file("extdata", "itol", package = "EthnoBotaPhyWR") provides precomputed Newick trees (.tre) and iTOL v6 annotation files (.txt) for Orchidaceae.

    All remaining helpers (tree caching, phylogenetic signal and ancestral state calculation, NPClassifier lookup, hierarchy rollup, and plotting) are internal to the package.

    Installation

    Bioconductor packages ggtree and ggtreeExtra are required imports. Install from r-universe (with CRAN and Bioconductor repositories enabled):

    install.packages(
  "EthnoBotaPhyWR",
  repos = c(
    "https://adafede.r-universe.dev",
    "https://davidgohel.r-universe.dev",
    "https://cran.r-universe.dev",
    "https://bioc.r-universe.dev"
  )
)

    Or install the development version from GitHub:

    remotes::install_github("adafede/EthnoBotaPhyWR")

    Documentation articles are published on the package site: Full pipeline tutorial and Orchids datasets.

    Quick start

    Inspect bundled datasets and iTOL files (offline)

    library(EthnoBotaPhyWR)

data(orchids_compounds)
data(orchids_compound_classes)
data(orchids_ethnobotanical)

dim(orchids_compounds)
dim(orchids_compound_classes)
dim(orchids_ethnobotanical)

itol_dir <- system.file("extdata", "itol", package = "EthnoBotaPhyWR")
list.files(itol_dir)

    Interactive exploration on iTOL

    To inspect either the bundled Orchidaceae outputs or files written to <dirname(export_table_counts)>/itol/ by ethnobotafever_tree():

    1. Upload one of the .tre files (*_full_genera_tree.tre, *_phyto_genera_tree.tre, or *_phyto_species_tree.tre) to https://itol.embl.de/upload.cgi.
    2. Drag and drop its three companion annotation files onto the tree canvas:
      • *_itol_ethnobotany.txt (DATASET_GRADIENT: \(\log_{10}\) ethnobotanical species count)
      • *_itol_species_richness.txt (DATASET_SIMPLEBAR: known species count per taxon)
      • *_itol_compounds_multibar.txt (DATASET_MULTIBAR: stacked compound superclass counts colored by pathway)

    Analyze a plant family (requires network access)

    out_dir <- file.path(tempdir(), "ethnobotaphywr_demo")
dir.create(out_dir, recursive = TRUE, showWarnings = FALSE)

result <- ethnobotafever_tree(
  taxon_name = "Orchidaceae",
  n_multiple_genera = 10L,
  n_ethnobotanical_count_min = 10L,
  n_compounds_count_min = 50L,
  example_family_names = c("Solanaceae", "Fabaceae"),
  path_molecules = orchids_compounds,
  path_classes = orchids_compound_classes,
  path_ethnobotanical = orchids_ethnobotanical,
  export_tree_full = file.path(out_dir, "orchids_tree_full.svg"),
  export_tree_phyto = file.path(out_dir, "orchids_tree_phyto.svg"),
  export_tree_phyto_sub = file.path(out_dir, "orchids_tree_phyto_sub.svg"),
  export_table_classified = file.path(out_dir, "orchids_classified.tsv"),
  export_table_counts = file.path(out_dir, "orchids_counts.tsv"),
  export_table_counts_sub = file.path(out_dir, "orchids_counts_sub.tsv"),
  local_cache = file.path(out_dir, "cache"),
  log_dir = out_dir
)

    Limitations

    • Source database bias and incompleteness: Wikidata and LOTUS record only published and digitized occurrences; zero or low counts for a taxon reflect lack of curated records rather than true biological absence.
    • Topological branch lengths: Open Tree of Life synthetic subtrees do not provide calibrated divergence times. Phylogenetic ancestral state reconstruction (method = "phylo") and Blomberg’s \(K\) use Grafen branch lengths as a topological approximation.
    • External service dependency: Running ethnobotafever_tree() without complete local tables and caches requires live HTTP access to QLever (Wikidata endpoint), the Open Tree of Life v3 API, and GNPS2 NPClassifier.
