Working with Orchids Datasets

EthnoBotaPhyWR includes three curated datasets for Orchidaceae (Orchids): phytochemical compounds, their classifications, and ethnobotanical uses.

Loading the Datasets

Load the package and available datasets:

library(EthnoBotaPhyWR)
#> Welcome to EthnoBotaPhyWR v0.0.0.9001
library(tidytable)
#> 
#> Attaching package: 'tidytable'
#> The following objects are masked from 'package:stats':
#> 
#>     dt, filter, lag
#> The following objects are masked from 'package:base':
#> 
#>     %in%, %notin%

# Load all three datasets
data(orchids_compounds)
data(orchids_compound_classes)
data(orchids_ethnobotanical)

cat("Loaded:\n")
#> Loaded:
cat("  orchids_compounds:", nrow(orchids_compounds), "rows\n")
#>   orchids_compounds: 3055 rows
cat("  orchids_compound_classes:", nrow(orchids_compound_classes), "rows\n")
#>   orchids_compound_classes: 1574 rows
cat("  orchids_ethnobotanical:", nrow(orchids_ethnobotanical), "rows\n")
#>   orchids_ethnobotanical: 419 rows

orchids_compounds

The orchids_compounds dataset links taxa to their reported chemical compounds, with SMILES strings and chemical classifiers.

head(orchids_compounds, 3)
#> # A tidytable: 3 × 10
#>   taxon    taxon_name          compound compound_smiles_cano…¹ compound_inchikey
#>   <chr>    <chr>               <chr>    <chr>                  <chr>            
#> 1 Q3055749 Epidendrum fulgens  Q100145… OC1CC2=CCC3C(CCC4(C)C… SGNBVLSWZMBQTH-S…
#> 2 Q3055749 Epidendrum fulgens  Q100145… OC1CC2=CCC3C(CCC4(C)C… SGNBVLSWZMBQTH-S…
#> 3 Q4987884 Bulbophyllum echin… Q100276… C(C(C(C(C(=O)O)O)O)O)O QXKAIJAYHKCRRA-U…
#> # ℹ abbreviated name: ¹​compound_smiles_canonical
#> # ℹ 5 more variables: connectivity_layer <chr>, pathway <chr>,
#> #   superclass <chr>, class <chr>, glycoside <lgl>

Structure

  • taxon: Wikidata QID for the species
  • taxon_name: Scientific name
  • compound: Wikidata QID for the compound
  • compound_smiles_canonical: Canonical SMILES representation
  • compound_inchikey: InChIKey identifier
  • connectivity_layer: InChIKey connectivity skeleton
  • pathway, superclass, class: NPClassifier taxonomy
  • glycoside: Logical flag for glycoside compounds

Analysis Examples

Count compounds per taxon:

orchids_compounds |>

    .by = taxon_name

  tidytable::arrange(-n_compounds) |>

orchids_compound_classes

The orchids_compound_classes dataset is a reference lookup for SMILES strings to their NPClassifier taxonomy.

#>   <chr>                                       <chr>   <chr>      <chr> <lgl>    
#> 1 OC1CC2=CCC3C(CCC4(C)C(CCC34)C(C)CCC(C)C(C)… Terpen… Steroids   Chol… FALSE    
#> 2 OC1CC2=CCC3C(CCC4(C)C(CCC34)C(C)CCC(C)C(C)… Terpen… Steroids   Ergo… FALSE

Structure

  • query: Canonical SMILES string
  • pathway, superclass, class: NPClassifier taxonomy
  • glycoside: Logical flag

orchids_ethnobotanical

The orchids_ethnobotanical dataset links species with documented ethnobotanical uses to their Open Tree of Life taxonomy identifiers.

head(orchids_ethnobotanical, 3)
#> # A tidytable: 3 × 3
#>   taxon_name       taxon     taxon_id_ott
#>   <chr>            <chr>     <chr>       
#> 1 Acampe carinata  Q15500570 3975442     
#> 2 Acampe papillosa Q24852981 649247      
#> 3 Acampe praemorsa Q4671836  292057

Structure

  • taxon_name: Scientific name
  • taxon: Wikidata QID
  • taxon_id_ott: Open Tree of Life identifier (for phylogenetic integration)

Integration with Phylogenetics

Use taxon_id_ott to build phylogenetic trees:

# Prepare data for tree building
tree_data <- orchids_ethnobotanical |>
  tidytable::mutate(
    compounds_count = 0, # or merge with orchids_compounds
    ethnobotanical_count = 1
  ) |>
  tidytable::distinct(taxon_id_ott, taxon_name, .keep_all = TRUE)

cat("Ready to use", nrow(tree_data), "OTT IDs for phylogenetics\n")
#> Ready to use 419 OTT IDs for phylogenetics
head(tree_data)
#> # A tidytable: 6 × 5
#>   taxon_name             taxon taxon_id_ott compounds_count ethnobotanical_count

Integration: Compounds × Ethnobotany

Combine datasets to analyze which species have both compounds and uses:

# Species with compounds
spp_compounds <- orchids_compounds |>
  tidytable::distinct(taxon, taxon_name)

# Species with ethnobotanical uses
spp_ethnobotany <- orchids_ethnobotanical |>
  tidytable::distinct(taxon, taxon_name)

# Find intersection
both <- tidytable::inner_join(
  spp_compounds,
  spp_ethnobotany,
  by = c("taxon", "taxon_name")
)

cat(
  "Species with both compounds AND ethnobotanical uses:",
  nrow(both), "/", nrow(spp_ethnobotany), "\n"
)
#> Species with both compounds AND ethnobotanical uses: 102 / 419

R-Universe Multi-Format Export

Because these datasets are flat data.frame objects, they qualify for r-universe multi-format export:

  • CSV, XLSX, JSON, NDJSON downloads
  • Machine-readable metadata
  • API access for downstream tools

See https://adafede.r-universe.dev/EthnoBotaPhyWR for format options.

Data Sources

All datasets are curated from:

  • Wikidata (https://www.wikidata.org/) — Taxonomic data and relationships
  • LOTUS (https://lotus.naturalproducts.net/) — Natural products database
  • NPClassifier (https://npclassifier.gnps2.org/) — Compound classification
  • Open Tree of Life (https://tree.opentreeoflife.org/) — Phylogenetic IDs
