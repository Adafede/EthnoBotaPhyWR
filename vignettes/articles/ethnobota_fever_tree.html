Using EthnoBotaPhyWR

Full pipeline tutorial for ethnobotanical and phytochemical analysis

This tutorial illustrates the complete ethnobotafever_tree() pipeline, from data retrieval via Wikidata to phylogenetic tree visualization.

Author
Affiliation

Adriano Rutz

ETH Zürich

Published

October 27, 2026

Abstract

This tutorial illustrates the use of EthnoBotaPhyWR (pronounced “Ethnobota Fever”), showing how to collect ethnobotanical and phytochemical data for a taxonomic family.

Keywords

Ethnobotany, Phytochemistry, Taxonomy, Wikidata, R, Phylogenetics, Natural products

EthnoBotaPhyWR stands for ethnobotany, phytochemistry, Wikidata and R (maybe you can also find the bot of robot) It should be pronounced “Ethnobota Fever”.

Introduction

This vignette illustrates how to collect data on the ethnobotanical uses, and the phytochemistry of a given taxonomic family. The data collected originate from Wikidata, the free knowledge base that anyone can edit.

At the moment, this vignette supports adding your own data and combine them with the ones available on Wikidata to see the results. Ideally, you should share these precious data.

tl;dr

The function you are looking for is ethnobotafever_tree(), whose parameters are described below:

## Taxonomy-related parameters
taxon_name <- "Orchidaceae" # The scientific name of the family you are interested in

example_family_names <- c( # The scientific name(s) of family(ies) you want to compare to
  "Poaceae" = "Poaceae",
  "Fabaceae" = "Fabaceae",
  "Asteraceae" = "Asteraceae",
  "Orchidaceae" = "Orchidaceae",
  "Rosaceae" = "Rosaceae",
  "Solanaceae" = "Solanaceae"
)

## Thresholds
n_multiple_genera <- 10L # The minimal number of genera where a compound was found in to consider the latter relatively widespread
n_ethnobotanical_count_min <- 10L # The minimal number of species within the genus for which an ethnobotanical use has been reported to consider the genus relatively widely used
n_compounds_count_min <- 50L # The minimal number of compounds reported in a taxon to consider the latter relatively widely investigated
## File paths
pkg_root <- tryCatch(
  {
    p <- "."
    for (i in seq_len(10L)) {
      if (file.exists(file.path(p, "DESCRIPTION")) && dir.exists(file.path(p, "data-raw"))) {
        break
      }
      p <- file.path(p, "..")
    }
    normalizePath(p)
  },
  error = function(e) normalizePath(".")
)
cache_dir <- file.path(pkg_root, "data")
log_dir <- file.path(pkg_root, "data-raw")
figures_dir <- file.path(pkg_root, "man", "figures")
dir.create(figures_dir, recursive = TRUE, showWarnings = FALSE)

path_molecules <- EthnoBotaPhyWR::orchids_compounds
path_classes <- EthnoBotaPhyWR::orchids_compound_classes
path_ethnobotanical <- EthnoBotaPhyWR::orchids_ethnobotanical

export_tree_full <- file.path(figures_dir, "tree_orchids_full.svg")
export_tree_phyto <- file.path(figures_dir, "tree_orchids_phyto.svg")
export_tree_phyto_sub <- file.path(figures_dir, "tree_orchids_phyto_sub.svg")
export_table_classified <- file.path(
  pkg_root,
  "data-raw",
  "orchids_table_unique_connectivity_classified.tsv"
)
export_table_counts <- file.path(pkg_root, "data-raw", "orchids_table_counts.tsv")
export_table_counts_sub <- file.path(
  pkg_root,
  "data-raw",
  "orchids_table_counts_sub.tsv"
)

local_cache <- cache_dir
dir.create(log_dir, recursive = TRUE, showWarnings = FALSE)

Change these parameters as required and you are ready for the fever!

results <- ethnobotafever_tree(
  taxon_name = taxon_name,
  n_multiple_genera = n_multiple_genera,
  n_ethnobotanical_count_min = n_ethnobotanical_count_min,
  n_compounds_count_min = n_compounds_count_min,
  example_family_names = example_family_names,
  path_molecules = path_molecules,
  path_classes = path_classes,
  path_ethnobotanical = path_ethnobotanical,
  export_tree_full = export_tree_full,
  export_tree_phyto = export_tree_phyto,
  export_tree_phyto_sub = export_tree_phyto_sub,
  export_table_classified = export_table_classified,
  export_table_counts = export_table_counts,
  export_table_counts_sub = export_table_counts_sub,
  local_cache = local_cache,
  log_dir = log_dir
)

Results

This will give you different objets

First, tables containing different information:

  • An overview of the phytochemistry of the family in Table 1
  • An overview of the number of reported uses, compounds, and species per genus within the family in Table 2
  • An overview of the species within the family for which a decent number of compounds or uses have been reported in Table 3

Second, some tree-based visualizations:

  • A tree with genera as tips, displaying the taxa of the family, and if compounds or uses have been reported in Figure 1 (mainly to show the majority remains non-investigated)
  • A tree with genera as tips, displaying the taxa of the family for which compounds or uses have been reported in Figure 2 (mainly to make them easier to read)
  • A tree with species as tips, displaying the taxa of the family for which a decent number of compounds or uses have been reported in the corresponding genus in Figure 3 (mainly to show that even in the most investigated genera, the coverage is far from ideal)
